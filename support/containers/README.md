## Описание

Создается сеть testapp `172.18.0.0/16`
http-морда управляется сервисом `proxy-http`, а запросы к ней резолвятся сервисом `proxy-dns`.
В нем зона `.test` врезолвится на адрес `proxy-http`

Все внутренние (от контейнера к контейнеру) могут идти по имени сервиса, либо через proxy-http
Если не надо, то сервис не должен торчать наружу.

## Управление

_Все команды выполняются в директории с проектом_

Запуск:

`podman-compose up -d --build`

Остановка:

`podman-compose down`

Непрерывый вывод логов всех контейнеров:

`podman-compose logs -f`

Зайти в контейнер:
`podman-compose exec <service_name> /bin/bash`

Или если контейнер без bash
`podman-compose exec <service_name> sh`
